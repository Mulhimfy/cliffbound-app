# Cliffbound: Mountain Climbing — app builds & website

This public repository holds the compiled game bundle and the native Android/iOS shells used to
build **Cliffbound**, plus the website (`docs/`, served by GitHub Pages).

- **Download the Android APK:** [Cliffbound.apk](https://github.com/Mulhimfy/cliffbound-app/releases/latest/download/Cliffbound.apk)
- **Website, privacy policy and support:** https://mulhimfy.github.io/cliffbound-app/

Cliffbound plays fully offline, shows no ads, has no accounts and collects no data.
